# 1. Présentation du Projet

## 1.1 Contexte
Golden Pousso est un salon de couture basé à Pikine Tally Boumack, spécialisé dans la mode africaine haut de gamme.  
L’objectif est de développer une présence digitale via un site e-commerce performant.

## 1.2 Objectifs
- Développer les ventes en ligne  
- Présenter les collections  
- Offrir une expérience fluide (mobile & desktop)  
- Transformer le site en application mobile (PWA)  
- Faciliter la gestion des produits  

## 1.3 Informations techniques
- Domaine : www.goldenpousso.com  
- Hébergement : Infomaniak (Suisse)  
- Existant : Page WordPress
